# T1.2 档案接口实现说明

> 覆盖 `03 §6.2 #1—#6` 的个体档案部分。群体、目击、出现记录、点位维护属 T1.5，状态迁移属 T1.3（引擎已先行完成）。

## 1 已实现接口

| 方法 | 路径 | 说明 | 主要规则 |
|---|---|---|---|
| POST | `/api/v1/animals` | 建档 | 服务端发号；前端传 `code` 返回 30411；特征 ≥5 字；照片 1—6 张；年龄 0—25 |
| GET | `/api/v1/animals` | 列表 | keyword / status / pointId / neutered / adopted 五条件组合；默认按 `updated_at` 倒序；page/size 夹紧 |
| GET | `/api/v1/animals/{code}` | 公开详情 | 不返回 `internalNote`；编号不存在 30410（HTTP 404） |
| PUT | `/api/v1/animals/{code}` | 编辑 | `reason` ≥5 字，否则 30401；按字段比较，变化才写日志；乐观锁冲突 50002 |
| GET | `/api/v1/animals/{code}/history` | 变更历史 | 返回 field / beforeValue / afterValue / reason / operatorId / createdAt |

## 2 分层落点

| 层 | 文件 |
|---|---|

## 3 发号与事务

1. `AnimalService.create` 开事务后调用 `DatabaseSequencePort.next`。
2. `seq_no` 先 `INSERT IGNORE` 确保行存在，再 `SELECT ... FOR UPDATE` 锁行，加一后写回。
3. 取号与 `animal` 插入在同一事务：建档失败会回滚流水，不跳号；并发下靠行锁不重号。
4. 编号格式 `类别-年份-流水`，流水三位起、超过三位自然增宽（现有编号器测试覆盖）。

## 4 编辑留痕口径

- 只比较请求中显式给出的字段（null 表示不改），不把未传字段写成空值。
- 每个变化字段一行 `animal_change_log`，`before_value` / `after_value` 存字符串，`reason` 与 `operator_id` 原样落库。
- 请求值与当前值完全一致时不写日志，也不触发 update。
- `internalNote` 属管理员字段，公开详情不返回；编辑接口暂按管理员接口处理。

## 5 已知缺口（联调前必须处理）

| 项 | 现状 | 处理 |
|---|---|---|
| 身份 | `X-User-Id` 请求头占位，默认为 0 | 等 A 的 JWT 与角色落地后替换，禁止把该头当可信身份 |
| 历史接口权限 | 任何人可读变更历史 | 加 `ANIMAL_ADMIN` 拦截 |
| 多图 | 只存首张为 `cover_file_id` | 其余照片待 `sys_file` 关联表确定后落 |
| 字典校验 | 花色只校验非空 | 等 A 的 `/dicts` 可用后校验字典项 |
| 编码校验 | 未校验 `code` 格式 | 由编号器保证；外部查询编号暂不做正则 |
