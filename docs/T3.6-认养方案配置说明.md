# T3.6 认养方案新增与编辑说明（成员 C｜D3 P1）

## 1. 范围

补齐交易域接口 1–3 中的写入口：`GET /plans` 管理员扩展、`POST /plans`、`PUT /plans/{id}`。公开读取仍沿用原有 `GET /plans`。

- 后端：`AdoptionPlanController`、`AdoptionPlanService`、`MyBatisAdoptionPlanRepository`
- 前端：`AdoptView` 增加“方案管理”入口，新增 `views/adopt/PlanManageView.vue`
- 文档：03 接口说明书 7.26–7.28

## 2. 业务口径

| 动作 | 规则 |
|---|---|
| 公开列表 | 只返回 `enabled=true`，不暴露停用方案 |
| 管理员列表 | `includeDisabled=true`，要求管理角色，否则 20003 |
| 新增 | 名称 1–32 字；周期 `MONTH / QUARTER`；金额为正整数（分）；权益 ≤255 字；启用默认 true |
| 编辑 | 请求体同新增；`enabled` 省略时保留原状态 |
| 审计 | 新增写 `PLAN_CREATE`，编辑写 `PLAN_UPDATE` |
| 存量关系 | 认养单已固化金额/周期，停用方案不影响历史单 |

金额统一按分存储，前端表单输入元，保存时 `Math.round(yuan * 100)`，展示用 `money()`。

## 3. 错误码

| 码 | 场景 |
|---|---|
| 20001 | 未登录调用写接口 |
| 20003 | 非管理员调用写接口或 `includeDisabled=true` |
| 30301 | 名称空/超长、金额非正、权益超长、周期缺失 |
| 30303 | 周期不是 `MONTH / QUARTER` |
| 30410 | 编辑的方案不存在 |
| 50002 | 更新 0 行 |

## 4. 前端

`PlanManageView` 以表格展示全部方案（含停用），支持新增、编辑、启停。新增/编辑弹窗校验名称与金额，权益可空。入口放在认养专区页头，仅管理员显示。

## 5. 边界

- 不做方案删除：历史认养单引用 `plan_id`，删除会破坏追溯；停用即可。
- 不限制同名方案：当前无唯一约束，运营可按周期建同名档位；若要唯一需另加约束与迁移。
- 金额上限未做业务封顶，仅要求正整数；演示数据按 A-01 口径。
